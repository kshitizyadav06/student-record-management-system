# 🎓 Student Record Management System (Python)

A simple command-line Student Record Management System built with Python as a learning project. It allows users to manage student records through CRUD (Create, Read, Update, Delete) operations while demonstrating clean code organization and reusable functions.

## 🚀 Features

* ➕ Add Student
* 📋 View All Students
* 🔍 Search Student by Name
* ✏️ Update Student Details
* ❌ Delete Student
* ✅ Age Input Validation
* 🧩 Modular Function-Based Design

## 🛠️ Technologies Used

* Python 3

## 📚 Concepts Practiced

* Variables
* Lists
* Dictionaries
* Functions
* Loops (`for`, `while`)
* `break` and `continue`
* `return`
* `try` / `except`
* Input Validation
* List of Dictionaries

* Break a larger program into smaller, focused functions.
